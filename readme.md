# 📰 NewsGrid - Sports Article Website 🏅

Welcome to **NewsGrid**, a dynamic platform dedicated to delivering the latest in sports news and articles. Whether you're into football, basketball, or tennis, NewsGrid keeps you up to date with engaging content, live updates, and expert analysis.

---

## 📋 Project Overview

**NewsGrid** is built for sports enthusiasts who want easy access to top sports stories from around the world. With a clean, grid-based layout, the site is designed to display multiple articles in an intuitive, easy-to-read format.

### Key Features:
- **Live Sports News**: Get real-time updates and breaking news on major sports events.
- **Responsive Design**: Access NewsGrid on any device, from mobile phones to desktops.
- **Article Categories**: Browse by sport—football, basketball, tennis, and more.
- **Shareable Content**: Share articles easily on social media platforms.

---

## 🛠️ Technologies Used

- **Front-End**: HTML5, CSS3 (Grid Layout), JavaScript
- **Back-End**: PHP for content management and dynamic page generation
- **Database**: MySQL to store article content and user interactions
